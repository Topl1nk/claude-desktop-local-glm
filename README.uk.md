# Claude Desktop на локальній моделі (GLM-4.7-Flash + Ollama)

Claude Desktop працює з локальною моделлю GLM-4.7-Flash через Ollama: без підписки й без хмари.
Звичайний Claude за підпискою можна запускати поруч, в окремому вікні.

- **Модель:** GLM-4.7-Flash, MoE 30B (активні ~3B), контекст до 131K. На i9-12900KS + RTX 3070 8 ГБ
  видає 30–32 токени/с.
- **Документи:** PDF, DOCX і скани (OCR) — через власний MCP-сервер `docs` і MinerU, усе локально.
- **Пошук в інтернеті:** власний SearXNG у Docker, без Docker — DuckDuckGo. Платні API не потрібні.
- **Два вікна одночасно:** «Claude - Local» із сірими іконками і «Claude - Subscription» з помаранчевими.

## Вимоги

| | Мінімум | Рекомендовано |
|---|---|---|
| Windows | 10/11 | 11 |
| ОЗП | 24 ГБ | 32–64 ГБ |
| Відеокарта | не обов'язкова (буде повільно) | NVIDIA від 8 ГБ |
| Диск | 25 ГБ вільно на диску з текою встановлення | SSD |
| Програми | [Claude Desktop](https://claude.ai/download) | + Docker Desktop для SearXNG |

Ollama, uv, MinerU і Visual C++ runtime інсталятор встановить сам: через winget, а якщо його немає —
офіційними інсталяторами розробників.

## Встановлення

1. Встановіть [Claude Desktop](https://claude.ai/download).
2. Завантажте цей репозиторій у теку без кирилиці, наприклад `C:\AI\Claude-Local`.
3. У PowerShell виконайте:

   ```powershell
   powershell -ExecutionPolicy Bypass -File C:\AI\Claude-Local\install.ps1
   ```

4. Запускайте ярлик **«Claude - Local»** на робочому столі.

Інсталятор сам підбере кількість потоків і довжину контексту під ваш комп'ютер, а повідомлення
покаже мовою Windows (англійська, українська або російська; примусово — `-Lang en|uk|ru`). Його можна
запускати повторно: готові кроки він пропустить. Наприкінці він виводить таблицю — що встановилося,
а що ні.

### Параметри

| Параметр | Що робить |
|---|---|
| `-ModelsDir <тека>` | Тримати моделі в іншому місці. За замовчуванням вони лягають у `models` всередині теки встановлення, тож уся система в одному місці; якщо в Ollama модель уже є, використовується її тека |
| `-ModelSource <тека>` | Скопіювати `glm-4.7-flash` з теки моделей Ollama, де вона вже завантажена (інший ПК, флешка), замість завантаження ~18 ГБ |
| `-ContextLength 65536`, `-Threads 8` | Замінити автоматичний вибір |
| `-NoSearxng` | Не запускати SearXNG (пошук тоді йде через DuckDuckGo) |

## Перевірено

`tests\sandbox-test.ps1` запускає інсталятор на чистій одноразовій Windows (Windows Sandbox, без
відеокарти): усі кроки й усі 7 перевірок проходять, включно з відповіддю моделі та OCR через MinerU.
