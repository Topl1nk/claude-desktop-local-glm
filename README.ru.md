# Claude Desktop на локальной модели (GLM-4.7-Flash + Ollama)

Claude Desktop работает с локальной моделью GLM-4.7-Flash через Ollama: без подписки и без облака.
Обычный Claude по подписке можно запускать рядом, в отдельном окне.

![Локальный Claude Desktop на GLM-4.7-Flash; серый ярлык — локальная версия, оранжевый — подписка](docs/screenshot.png)

- **Модель:** GLM-4.7-Flash, MoE 30B (активны ~3B), контекст до 131K. На i9-12900KS + RTX 3070 8 ГБ
  выдаёт 30–32 токена/с.
- **Документы:** PDF, DOCX и сканы (OCR) — через свой MCP-сервер `docs` и MinerU, всё локально.
- **Поиск в интернете:** свой SearXNG в Docker, без Docker — DuckDuckGo. Платные API не нужны.
- **Два окна одновременно:** «Claude - Local» с серыми иконками и «Claude - Subscription» с оранжевыми.

## Требования

| | Минимум | Рекомендуется |
|---|---|---|
| Windows | 10/11 | 11 |
| ОЗУ | 24 ГБ | 32–64 ГБ |
| Видеокарта | не обязательна (будет медленно) | NVIDIA от 8 ГБ |
| Диск | 25 ГБ свободно на диске с папкой установки | SSD |
| Программы | [Claude Desktop](https://claude.ai/download) | + Docker Desktop для SearXNG |

Ollama, uv, MinerU и Visual C++ runtime установщик поставит сам: через winget, а если его нет —
официальными установщиками разработчиков.

## Установка

1. Установите [Claude Desktop](https://claude.ai/download).
2. Скачайте последний релиз — **Source code (zip)** на [странице релизов](https://github.com/Topl1nk/claude-desktop-local-glm/releases/latest) — и распакуйте
   его в папку без кириллицы, например `C:\AI\Claude-Local`.
3. В PowerShell выполните:

   ```powershell
   powershell -ExecutionPolicy Bypass -File C:\AI\Claude-Local\install.ps1
   ```

4. Запускайте ярлык **«Claude - Local»** на рабочем столе.

Установщик сам подберёт число потоков и длину контекста под ваш компьютер, а сообщения покажет на
языке Windows (английский, украинский или русский; принудительно — `-Lang en|uk|ru`). Его можно
запускать повторно: готовые шаги он пропустит. В конце он выводит таблицу — что установилось, а что нет.

### Параметры

| Параметр | Что делает |
|---|---|
| `-ModelsDir <папка>` | Держать модели в другом месте. По умолчанию они ложатся в `models` внутри папки установки, так что вся система в одном месте; если в Ollama модель уже есть, используется её папка |
| `-ModelSource <папка>` | Скопировать `glm-4.7-flash` из папки моделей Ollama, где она уже скачана (другой ПК, флешка), вместо скачивания ~18 ГБ |
| `-ContextLength 65536`, `-Threads 8` | Заменить автоматический выбор |
| `-NoSearxng` | Не запускать SearXNG (поиск тогда идёт через DuckDuckGo) |

## Проверено

`tests\sandbox-test.ps1` запускает установщик на чистой одноразовой Windows (Windows Sandbox, без
видеокарты): все шаги и все 7 проверок проходят, включая ответ модели и OCR через MinerU.
